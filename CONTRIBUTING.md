# Contributing

1. Open an issue describing the bug or proposed improvement.
2. Include a small reproducible example where possible.
3. Add or update unit or Express integration tests for behavior changes.
4. Run `npm run check`, `npm test`, and `npm pack --dry-run` before opening a pull request.
5. Keep public APIs, supported Node.js/Express versions, and error messages documented in `README.md`.
6. Follow semantic versioning and update `CHANGELOG.md` when behavior changes.

Do not include real passwords, access tokens, private user data, or production request payloads in issues or tests.
